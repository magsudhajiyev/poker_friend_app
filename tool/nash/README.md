# Nash push/fold table generation

`lib/services/drill_nash_pushfold.dart` is GENERATED by this pipeline:

    dart compute_nash.dart 30000 > nash_output.txt
    python3 generate_dart.py nash_output.txt ../../lib/services/drill_nash_pushfold.dart

Pipeline: 7-card evaluator (exact-enumeration validated: AKs vs QQ = 0.4621,
72o vs AA = 0.1258) → 169×169 Monte Carlo equity matrix (30k samples/pair,
±0.3%) → damped best-response iteration to the jam/call Nash equilibrium.
SB-vs-BB is the exact equilibrium; earlier positions use the standard
fold-through approximation. Output matches the classic published values
(SB@10BB jam ≈ 58%, BB call ≈ 37%).

All data is self-computed — no licensed chart pack is copied.
